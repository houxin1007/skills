# 格式指南

## 文件位置
`<项目根目录>/.codex/session-context.md`

## 结构建议
格式自由，以下是一种推荐结构：

```markdown
# 项目: <项目名>

## 当前进度
- 步骤: <当前在做什么>
- 下一步: <接下来做什么>

## 关键决策
- <日期>: <决策内容> — 理由: <为什么>

## 约定与约束
- <项目特定的规范、命名约定、技术限制>

## 踩坑记录
- <问题>: <解决方案>

## 用户偏好
- <用户明确表达的习惯或要求>
```

## 更新规则
- 每次更新在对应区块追加，不覆盖历史
- 过时信息直接删除或标记 ~删除线~
- 控制文件在 200 行以内，超出则清理旧内容
- 优先保留方向性信息和关键决策
