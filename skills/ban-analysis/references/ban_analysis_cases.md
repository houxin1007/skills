﻿# Ban位分析案例

## 案例1: 神龙平 (神无月+龙珏+平将门)

**命令:**
`ash
python scripts/ban_analysis.py --our 596,573,592 --dt-start 2026-07-20 --dt-end 2026-07-26 --name "神龙平"
`

**结果: 葛叶(597) ✅ BAN位确认**

| 指标 | 数据 |
|------|:----:|
| 阵容总场次 | 25,889 |
| 葛叶全局对方出现率 | 13.7% |
| 神龙平对局出现率 | 1.7% |
| 跌幅 | 87.3% |
| 50人验证: 0次出现 | 43/50人 (86.0%) |
| 分布 | 0次=43人, 1~5次=3人, >5次=4人 |

## 案例2: 面因龙珏 (面灵气+因幡辉夜姬+龙珏)

## 案例3: 卑因茶 (卑弥呼+因幡辉夜姬+SP时曜泷夜叉姬)

**命令:**
`ash
python scripts/ban_analysis.py --our 583,372,584 --dt-start 2026-07-20 --dt-end 2026-07-26 --name "卑因茶"
`

**结果: 葛叶(597) ⚠️ 高度疑似 (56%玩家ban)**

| 指标 | 数据 |
|------|:----:|
| 阵容总场次 | 16,911 |
| 葛叶全局对方出现率 | 13.7% |
| 卑因茶对局出现率 | 5.9% |
| 跌幅 | 56.5% |
| 50人验证: 0次出现 | 28/50人 (56.0%) |
| 分布 | 0次=28人, 1~5次=12人, >5次=10人 |

> 说明: 该阵容ban位不太统一, 约56%的高频玩家ban葛叶, 其余可能ban封阳君或其他。Top20玩家中有80% ban葛叶, 说明高分段更倾向于ban葛叶。
> 机制: 卑弥呼+SP茶需要稳定的行动条控制, 葛叶的加速/多动机制打乱节奏

## 判定标准

| 条件 | 判定 |
|------|:----:|
| 跌幅 >= 80% 且 50人验证 >= 80% 从未出现 | BAN位确认 ✅ |
| 跌幅 >= 50% 且 50人验证 >= 50% 但 < 80% | 高度疑似 ⚠️ |
| 跌幅 >= 80% 但 50人验证 < 50% | 非ban位(可能是阵容天然克制) |
| 跌幅 < 50% | 不是ban位 |
